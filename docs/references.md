# Design references and reuse decisions

These were consulted as technical/design references. They are **not** a list of bundled assets. All game models, shaders, maps and sound remain original procedural implementations in this checkout. No downloaded demo repository was executed. Dependency notices are separate in [THIRD_PARTY.md](../THIRD_PARTY.md).

| Reference                                                                                                                                                                                             | Useful direction / review result                                                                                                    | What is actually reused                                                                                                    |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| [Three.js car materials](https://threejs.org/examples/webgl_materials_car.html)                                                                                                                       | Separate paint/glass/trim and materials; Ferrari model credited separately to a Sketchfab author                                    | Three.js API only; original bevelled body, independent wheels and clearcoat material. No Ferrari, AO texture or branding   |
| [Seaside Town Scooter](https://phi-sato.itch.io/seaside-town-scooter)                                                                                                                                 | Reader could not access this page; content/license not verified                                                                     | Nothing copied; no claim of having inspected its visuals                                                                   |
| [Kirilbt bike source](https://github.com/Kirilbt/bike-demo-threejs), [demo](https://bike-demo-threejs.vercel.app/)                                                                                    | Components/material organization; no redistribution license established for source/model                                            | Original frame, wheel, steering, pedal and rider geometry; no downloaded GLB or code                                       |
| [Deathchase showcase](https://discourse.threejs.org/t/deathchase-3d-three-js-homage-to-the-1983-zx-spectrum-game-classic/91664)                                                                       | Damped lean, instancing and obstacle avoidance as general techniques; no explicit open-source redistribution permission established | Independent implementation only; no code, models, audio or combat mechanics                                                |
| [Three.js additive animation example](https://threejs.org/examples/#webgl_animation_skinning_additive_blending)                                                                                       | Distinct locomotion/pose layers and smooth transitions; example code and model rights must be treated separately                    | Procedural joint groups and speed-linked gait/pedalling. No Xbot/Mixamo asset and no claim of a skinned AnimationMixer rig |
| [Human model viewer](https://hmthanh.github.io/3d-human-model/), [anatomy discussion](https://discourse.threejs.org/t/a-3d-interactive-system-for-exploring-human-anatomy-by-anatomical-layers/88813) | Proportion/articulation reference; redistributable model rights not established; discussion is a request for advice                 | Original stylized characters, no anatomical layers or imported human GLBs                                                  |
| [ThreeJS Water demo](https://jeantimex.github.io/threejs-water/), [source](https://github.com/jeantimex/threejs-water)                                                                                | Bounded pool simulation with reflections/refractions and caustics; code license and tile/model licenses are separate                | Original analytic wave/shore shader, no source code, pool textures, duck or simulation copied                              |
| [DAT City](https://threejsresources.com/showcase/dat-city)                                                                                                                                            | Reader returned 403; license/content not verified                                                                                   | Nothing copied                                                                                                             |
| [City Tour](https://github.com/jstrait/city-tour)                                                                                                                                                     | MIT source attributed to Joel Strait; useful separation of roads, parcels and buildings, with instancing                            | Conceptual organization only; original street data, geometry and collider/minimap pipeline; no code or textures copied     |
| [WebGL Wind source](https://github.com/mapbox/webgl-wind), [demo](https://mapbox.github.io/webgl-wind/demo/)                                                                                          | ISC code for GPU weather-particle data visualization; data/tool licensing is a separate question                                    | No code, weather data, API or map imported; original low-amplitude shared-time leaf deformation                            |
| [Wind simulation discussion](https://discourse.threejs.org/t/wind-simulation-prototype/91753)                                                                                                         | Presentation of a prototype with mapping/data provenance questions                                                                  | No map/data or code copied; the game needs cosmetic vegetation breeze, not a weather globe                                 |

User-provided reference screenshots were materialized and visually inspected privately to review vehicle scale and rectangular minimap layout. They must remain excluded from a source release. The comparison fixture and screenshots in `evidence/` use only the project's own models/world.
